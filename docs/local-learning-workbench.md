# 单页本地学习工作台 · 2026-11-13

用户最新要求优先于此前双窗口、共享服务为默认权威的设计。本轮已把知识入口并回 Dingmi 主窗口；新资料库使用本机 SQLite，AI 和微信共用右侧栏。

## 入口与数据

- 双击 `启动贾维斯测试版.cmd` → `scripts/start-preview.ps1` → `target/debug/examples/fusion-preview.exe`。窗口标题「贾维斯管家 · 单页本地版」。预览入口带有 Windows Common-Controls v6 清单，避免原生启动时缺少系统控件入口。
- 本轮可用版本是开发预览，未完成正式安装包与公开发布。
- 用户预览目录固定为 `%LOCALAPPDATA%\JarvisButlerDesktop\local-workbench`。旧 user-preview、自动化临时目录和贾维斯正式数据保留，不会自动搬入。
- `dingmi.db`：原生笔记、提醒、设置、字符串ID映射；`workspace.db`：六表快照、业务回执、原文收件箱、本机会话与回顾进度。附件保留在本机目录。
- 新资料库无需同步服务。已有共享目录按原来保存的源站配置继续工作；本地知识记录非空时禁止直接切换源站。归档会话从不进入共享六表快照。
- 本机数据库是明文SQLite。模型密钥与微信认证信息使用按数据目录隔离的Windows凭据管理器。使用云端模型会发送用户选定的资料、对话和附件；本机Ollama可让推理留在本机。

AI对话是只读建议，不拥有终端或任意文件操作权限。详情里用户可显式选择“用所选模型整理为本机笔记”：先保存原文Source，再整理Note并建立derived_from关系。失败保留原文，重试走已有步骤回执。文字之外的会话附件不作为本轮导入内容。

学习回顾由用户在界面启用并选择本地整点时间。按1、3、7、14、30天检查，每次最多5条，优先用户标为重要的会话；原生托盘进程生成一条当日桌面提醒。会话摘要卡直接摘录原回答，不额外调用模型。点“已回顾”写入进度；点“回到原会话”可追溯原文。关闭窗口后托盘继续；关机和退出进程时不工作，下次运行补当天到期提醒。每日提醒留在桌面，不上传旧共享服务。
