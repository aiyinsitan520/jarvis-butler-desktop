# 贾维斯管家0.4.4测试版

修复“随手记”输入框提示换行后被裁切：改为“记点什么，或设个提醒…”，输入区较窄时隐藏右侧快捷键提示，多行记录继续自动增高。保留白猫图标与原有知识管理能力。

软件更新提供版本检查、更新记录、进度、测试／稳定渠道和自动检查偏好；安装必须确认，先保存编辑、备份两库，再核对签名与版本并覆盖升级。0.4.3起可在应用内检查升级；0.4.2及以前首次需手动安装本包。

Windows x64为NSIS，Mac Apple Silicon的DMG用于首次安装，app.tar.gz与sig用于更新。Mac未公证，真机安装与升级待本人验收；Windows无商业代码签名，更新签名与系统代码签名不同。
